API Integratsiya Qo'llanmasi

Word hujjatlaridan samarali ravishda solishtirish va o'xshashlik foizini hisoblash uchun Doc-Scan API yordamida ilovangizni modernizatsiya qiling.

1. Asosiy Ma'lumotlar

Ushbu hujjat API bilan frontend va boshqa mikrosevislarni ulanishini tushuntiradi. API hujjat ichidagi matnni `s2` dagi matn bilan bog'liqlik kuchi orqali topib, tahlil qilib beradi.

🔗

http://localhost:8000
🌍

https://scan.ekomplektasiya.uz

Swagger / ReDoc

/docs yoki /redoc

2. Hujjatni Tahlil Qilish Endpoint'i

Ushbu endpoint hujjatdagi "Xaridlar maqsadi" qismini tortib oladi va uni `s2` nomli parametr sifatida yuborilgan tartiblangan qatorlar bilan taqqoslaydi.

POST /analyze

So'rov (Request) parametrlari

Parametr nomi Turi Majburiymi? Ta'rifi
file File (.docx, .doc) Ha Tahlil qilinishi kerak bo'lgan Word hujjati.
s2 String Ha Solishtirish uchun ro'yxat tartibida shakllangan matn (Masalan: `1. M400 sement...`)

Muvaffaqiyatli Javob (200 OK)

Tizim ishlab bo'lgach muvaffaqiyatli natijani shunday shaklda qaytaradi:

{
  "status_code": 200,
  "error": "",
  "results": [
    {
      "row": 1,
      "s1": "1. Payvandlash qurilmasi uchun (Kabil) - 200 п/м",
      "s2": "1. Payvandlash qurilmasi uchun (Kabil) Проволка сварочная - 200 п/м",
      "concurrence": "98.50"
    },
    {
      "row": 2,
      "s1": "MOS RAQAMLI BAND TOPILMADI (S1 da yo'q)",
      "s2": "2. Avtogen shlangi шланг для автогена - 200 п/м",
      "concurrence": "0.00"
    }
  ]
}
  • s1 - Word fayldan topilgan qator.
  • s2 - Foydalanuvchi qidirayotgan qator.
  • concurrence - Matematik o'xshashlik foizi string ko'rinishida (Masalan "98.50").

3. Xatoliklar (Error Handling)

Agar ma'lumot topilmasa yoki tizim xatosi yuz bersa, API `error` string bandi orqali xatolikni aytadi.

400 Bad Request

Fayl yoki matnda tegishli 1., 2. ko'rinishidagi ro'yxat tizimi topilmaganda ro'y beradi.

404 Not Found

"Xaridlar maqsadi" so'zi Word hujjatingizdan mutlaqo topilmaganda ro'y beradi.

500 Server Error

O'qish jarayoni vaqtida yuzaga keladigan server xatoligi bo'yicha.

4. Integratsiya Misollari

React/Vue yoki toza JavaScript loyihalari uchun:

async function analyzeDocument(file, s2Text) {
    const formData = new FormData();
    formData.append("file", file); // DOM dagi input.files[0]
    formData.append("s2", s2Text); // String matni

    try {
        const response = await fetch("http://localhost:8000/analyze", {
            method: "POST",
            body: formData,
        });

        const data = await response.json();

        if (data.status_code === 200) {
            console.log("Topilgan ma'lumotlar:", data.results);
        } else {
            console.error("Xatolik xabari:", data.error);
        }
    } catch (error) {
        console.error("Tarmoq xatoligi:", error);
    }
}

Boshqa bir Django yoki FastAPI loyihalari orqali murojaat qilish:

import requests

url = "http://localhost:8000/analyze"
file_path = "document.docx"
s2_text = "1. M400 sement \n 2. Temir plita"

with open(file_path, "rb") as f:
    response = requests.post(
        url, 
        files={"file": f}, 
        data={"s2": s2_text}
    )
    
    result = response.json()
    if result["status_code"] == 200:
        for row in result["results"]:
            print(f"{row['row']}. {row['concurrence']}% o'xshash")
    else:
        print("Xatolik:", result["error"])

Server terminalidan to'g'ridan to'g'ri test qilib ko'rish:

curl -X 'POST' \
  'http://localhost:8000/analyze' \
  -H 'accept: application/json' \
  -H 'Content-Type: multipart/form-data' \
  -F 'file=@hujjat.docx;type=application/vnd.openxmlformats-officedocument.wordprocessingml.document' \
  -F 's2=1. Payvandlash qurilmasi uchun'

5. Muhim Jihatlar

Muhim: AI modeli (SentenceTransformers) so'rovni tahlil qilish uchun ko'proq vaqt talab qiladi. Integratsiya vaqtida foydalanuvchi interfeysida albatta Loader yoki Spinner ko'rsating!
  • Cors Politikasi: CORS muammosi bo'lmasligi uchun barcha so'rovlar (`allow_origins=["*"]`) ochilgan.
  • Raqamli Matn: Word fayli va s2 dagi barcha izlanadigan qatorda qat'iyan 1. kabi tartib raqami kiriting. Aks holda API bandlarni izolyatsiya qilolmaydi.
